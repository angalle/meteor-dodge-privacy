Meteor Dodge 개인정보 처리방침 (Privacy Policy)

최종 갱신: 2026-10-05 · 적용 대상: Meteor Dodge (Android / Google Play 배포)

1. 수집하는 개인정보 — 없음

Meteor Dodge 는 어떤 개인정보도 수집하지 않습니다. 회원가입·로그인·설문이 없고, 광고 식별자·기기 식별자·위치·연락처·사진·마이크·사용 로그를 수집하지 않습니다. 제3자에게 제공하거나 국외로 이전하는 데이터도 없습니다.

수집 항목 요약
수집하는 개인정보 항목 없음
자동 수집 정보 없음 (광고·분석·크래시 수집 없음)
제3자 제공·공유 없음
보유·이용 기간 / 파기 해당 없음 (수집하지 않으므로 보유하지 않음)

이 게임은 오프라인 우선으로 동작하며, 게임 플레이 중 서버로 전송되는 데이터가 없습니다.

2. 기기에만 저장되는 정보 (서버 전송 없음)

기기 로컬 저장 항목
저장 항목 저장 위치 목적 전송
최고 점수 1개 값 (bestScore) 기기 로컬 저장소 (브라우저 localStorage) 다음 판에 최고 점수 표시 전송 안 함
  • 위 값은 기기를 벗어나지 않으며, 개발자·제3자가 열람할 수 없습니다.
  • 앱 삭제(또는 앱 데이터/사이트 데이터 삭제) 시 함께 삭제됩니다.
  • 문자·숫자 점수 1개로 개인을 식별할 수 없습니다.

3. 제3자 SDK · 권한

  • 제3자 SDK: 없음 (광고·분석·크래시 수집·소셜 로그인 SDK 미포함)
  • 요청하는 권한: 없음 (위치·연락처·카메라·사진·마이크·저장소 읽기 권한을 요청하지 않습니다)
  • 네트워크 사용: 게임 플레이에 불필요 — 오프라인에서 전체 기능이 동작합니다
  • 인앱 결제: 없음 / 광고: 없음

4. 아동의 개인정보

만 14세 미만 아동을 포함한 모든 사용자로부터 개인정보를 수집하지 않습니다. 수집 항목이 0건이므로 아동 대상 별도 수집·보호자 동의 절차가 필요하지 않습니다.

5. 이용자의 권리

수집·이용하는 개인정보가 없으므로 열람·정정·삭제·처리정지 요청의 대상이 존재하지 않습니다. 기기에 저장된 최고 점수는 앱 데이터를 삭제하면 즉시 제거됩니다.

6. 방침 변경

이 방침을 변경하면 이 페이지의 내용과 최종 갱신일을 갱신하고, Play 스토어 등록 정보(데이터 보호 양식)도 함께 갱신합니다. 수집 항목이 새로 생기는 경우(예: 광고·분석 도입)에는 사전에 이 방침을 개정하고 알립니다.

7. 문의처

개발자 / 문의 이메일: Play Console 등록 정보의 개발자 연락처를 사용합니다 (등록 시 입력하는 값이며, 이 페이지에는 개인 이메일을 적지 않습니다). Play 스토어 앱 페이지의 "개발자에게 문의" 경로로도 연락할 수 있습니다.

이 페이지는 Play Console 에 등록할 개인정보 처리방침 URL 용 정적 HTML 입니다. Markdown 정본은 저장소의 store/privacy-policy.md 이며, 두 파일은 함께 갱신합니다.
